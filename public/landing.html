Issue 01 / The problem

Paper is fast, but it doesn’t scale.

I’d been planning my week on a stack of sheets for years. Three things kept breaking.

scattered

Lists live everywhere.

Work sheet on the desk. Family list on the fridge. SWE goals in a notebook. None of them know about each other.

cluttered

Done items pile up.

By Wednesday the sheet is half-ticked, mostly noise. Re-copying the survivors onto a fresh page is the whole ritual.

out of sync

Today & Week drift.

Today says “reply to Andre.” The category sheet still has it unchecked. Now both pages are wrong.

Issue 02 / The solution

One screen, shaped like a desk.

70% board on the left, 30% Today/Week on the right. The same items, in two views — always in sync.

Each board is one area of life. Each card on the board is a category. Each line is a task. Tick a task anywhere — in the card, in Today, in Week — and it’s ticked everywhere. At local midnight, completed Today items quietly drop away. At Monday 00:00, completed Week items follow. Anything still unticked carries over.

Brainstorm freely.
Tick what’s done.
Carry the rest.

Feature 06 / Backup & portability

Your data, on your machine.

Garap lives in your browser’s IndexedDB. No server, no sync, no account. For backup or moving between machines, export everything to a JSON file and import it back. The file is the format. It’s yours.

export

garap-2026-05-17.json

A single, readable file. Diffable. Versionable. Replaces the entire DB on import.

// schema: { boards, cards, items, todayRefs, weekRefs }
{
  "boards": [
    { "id": "b1", "name": "Work — Q2" },
    { "id": "b2", "name": "Dad" }
  ],
  "cards": [/* … */],
  "items": [
    { "id": "i17",
      "cardId": "c4",
      "name": "Review PR #142",
      "completed": false }
  ],
  "todayRefs": [{ "itemId": "i17" }],
  "weekRefs":  []
}

import

Replace, with a prompt.

Import is destructive by design — the file becomes the entire DB. A confirmation makes the step explicit.

Disaster-recovery in one click. Browser cleared? Drop the JSON back in. Switching laptops? Same file works.

issue 04 / colophon

A deliberately small piece of software.

Garap was built to replace a stack of paper sheets and nothing more. There is no account system, no cloud, no analytics, no AI assist. Your boards, cards, and items live in your browser’s IndexedDB — the same place your bookmarks and history live. The JSON export is the only way data leaves the device, and that’s entirely on you.

The aesthetic is on purpose too. It’s called a personal broadsheet: a one-reader newspaper. Smallcaps eyebrows over Work Sans display. A single indigo accent. Everything else is restraint.
